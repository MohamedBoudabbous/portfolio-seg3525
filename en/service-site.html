Ottawa Barber Studio

Booking website prototype for an Ottawa barber studio, designed through a user-centered design process.

React UI / UX UCD Figma

Project Overview

Ottawa Barber Studio is an interactive prototype created for the service website assignment in SEG3525. The project includes two distinct user journeys: a quick student haircut booking flow and a premium booking experience for a client who wants to choose a barber, a service, and a precise appointment time.

The final website connects the Figma mockups to a functional React prototype. It includes an access page, navigation between the two user journeys, interactive choices, a booking summary, and a final confirmation screen.

UCD Process

1. Understand

Defined the needs of two personas: Amir, who wants a fast student booking, and Daniel, who wants a premium experience.

2. Design

Created two storyboards with three mockups each to represent the main steps of the user journey.

3. Prototype

Translated the mockups into a React interface with services, barbers, date selection and dynamic confirmation.

4. Improve

Iterated on visual hierarchy, contrast, buttons, readability, negative space and separation between the two styles.

Main UX Decisions

  • Two separated visual identities: blue/black/white for the student flow, black/beige/gold for the premium flow.
  • Reduced friction by showing visible choices instead of hiding key options in dropdowns when speed matters.
  • Kept the booking summary visible before confirmation to reduce user errors.
  • Clear hierarchy: title, primary action, essential details, then confirmation.
  • Added a first access page to simulate entry into the service without requiring backend verification.
