Project overview

NeuroMatch turns the classic memory-card game into a richer interactive experience: players can choose a game mode, a difficulty level and a visual theme before starting.

The prototype focuses on clear interface hierarchy, immediate feedback, scoring, local best-score storage and responsive gameplay.

Game modes

Classic Match

Find every pair with the lowest number of attempts and mistakes.

Sequence Recall

Memorize a sequence of symbols and reproduce it in the correct order.

Focus Challenge

Play against a timer with mistake penalties to test sustained attention.

Design decisions

Readability

Clear hierarchy, readable cards and visual feedback to guide the player.

Progression

Beginner, Intermediate and Advanced levels adapt the challenge.

Accessibility

Contrast, labels, keyboard navigation and helper text are built into the interface.
