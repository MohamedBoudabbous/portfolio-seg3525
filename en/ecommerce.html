SEG3525 — User Interface Design and Analysis

NovaDesk

A React e-commerce prototype for student workspace accessories, designed to demonstrate faceted search, inventory-aware shopping, a guided checkout flow and a user feedback survey.

React E-Commerce UX / UI Faceted Search
Open Prototype View GitHub Repository

Project Overview

NovaDesk is a high-fidelity e-commerce prototype designed for students who want to improve their study and work environment. The store presents desk accessories, organization tools, lighting, writing products, audio products and bags.

The main goal was to design a clear, interactive and credible shopping interface while meeting the SEG3525 requirements: divergent and convergent exploration, guided process, user communication, accessibility and evaluation with Nielsen’s usability heuristics.

Problem

An e-commerce catalog can quickly become difficult to use when products, filters, cart actions and checkout steps are not clearly organized.

Solution

NovaDesk structures the experience around faceted search, readable product cards, a detailed cart and a step-by-step checkout flow.

Result

The prototype allows users to search, filter, add products to the cart, check inventory, simulate an order and submit UX feedback.

Integrated Interaction Processes

The prototype includes the three interaction processes required for the assignment.

Process 1

Faceted Search

Users can explore the full catalog and then narrow the results using multiple filters: category, study goal, color, material, maximum price and eco-friendly option.

This supports divergent exploration at the beginning, followed by a more precise convergent selection.

Process 2

Guided Checkout

The checkout is divided into visible steps: cart review, contact information, simulated payment and confirmation.

Users always know where they are, what has been completed and what remains to be done.

Process 3

UX Survey

After the shopping experience, users can rate the prototype, answer whether it was useful and leave an optional comment.

This section represents the communication process between the system and the user.

Main Features

  • Catalog of 20 NovaDesk products.
  • Filters by category, study goal, color, material, price and eco option.
  • Active filter badges with quick removal.
  • Product cards with image, price, description, rating and tags.
  • Display of available stock, cart quantity and remaining stock.
  • Cart with add, remove and quantity controls.
  • Inventory protection when the stock limit is reached.
  • Order summary with subtotal, estimated taxes and total.
  • Forms with validation and clear error messages.
  • Order confirmation and satisfaction survey.

UI / UX Design Decisions

Visual Hierarchy

Titles, prices, buttons and inventory information use a clear visual hierarchy to help users understand available actions quickly.

Consistency

Cards, buttons, badges and forms reuse consistent styles to make the interface predictable and easy to learn.

Error Prevention

The prototype prevents users from exceeding available stock and clearly states that the payment process is simulated.

Accessibility

The interface was designed with accessibility principles in mind to improve the experience for keyboard users, screen reader users and small screen users.

  • Real buttons are used for interactive actions.
  • Product images include alternative text.
  • Visible focus states support keyboard navigation.
  • Error messages are displayed close to invalid fields.
  • Form fields use explicit labels.
  • The layout is responsive on mobile, tablet and desktop.
  • Important buttons and badges use strong visual contrast.

Evaluation with Nielsen’s Heuristics

The prototype applies Nielsen’s ten usability heuristics through visible interface elements.

1. Visibility of System Status

The number of displayed products, active filters, cart counter, checkout steps and order confirmation constantly communicate the system status.

2. Match Between System and Real World

Terms such as cart, stock, price, delivery, payment and confirmation match common e-commerce vocabulary.

3. User Control and Freedom

Users can remove a product, change quantities, clear the cart, go back during checkout or return to the catalog.

4. Consistency and Standards

Buttons, cards, fields, badges and messages follow a consistent visual logic throughout the prototype.

5. Error Prevention

The system prevents users from adding more items than the available stock and clearly identifies the payment as simulated.

6. Recognition Rather Than Recall

Active filters, categories, tags, prices and checkout steps remain visible to reduce the user’s memory load.

7. Flexibility and Efficiency of Use

Users can quickly combine several filters, remove one specific filter or reset the full search.

8. Aesthetic and Minimalist Design

The interface uses spacious cards, a coherent palette, readable typography and content limited to useful information.

9. Help Users Recognize and Recover from Errors

Form errors are displayed near the relevant field with a clear message, for example for email, postal code or expiry date.

10. Help and Documentation

The prototype includes helper text, filter descriptions, a simulated payment warning and a footer explaining the overall experience.
