Ottawa Barber Studio

Prototype de site de réservation pour un salon de barbier à Ottawa, conçu avec une démarche de conception centrée utilisateur.

React UI / UX CCU Figma

Présentation du projet

Ottawa Barber Studio est un prototype interactif développé pour le devoir de site de service du cours SEG3525. Le projet présente deux parcours utilisateurs distincts : une réservation rapide pour étudiant et une expérience premium pour un client qui souhaite choisir un barbier, un service et une heure précise.

Le site final relie les maquettes Figma à un prototype React fonctionnel. Il inclut une première page d’accès, une navigation entre les deux parcours, des choix interactifs, un résumé de réservation et une confirmation finale.

Processus CCU

1. Comprendre

Définition des besoins de deux personas : Amir, qui cherche une réservation étudiante rapide, et Daniel, qui veut une expérience premium.

2. Concevoir

Création de deux scénarimages avec trois maquettes chacun afin de représenter les étapes principales du parcours utilisateur.

3. Prototyper

Transformation des maquettes en interface React avec services, barbiers, choix de date et confirmation dynamique.

4. Améliorer

Itérations sur la hiérarchie visuelle, les contrastes, les boutons, la lisibilité, l’espace négatif et la séparation des deux styles.

Choix UX principaux

  • Deux identités visuelles séparées : bleu/noir/blanc pour le parcours étudiant, noir/beige/doré pour le parcours premium.
  • Réduction de la friction avec des choix visibles au lieu de menus cachés lorsque cela améliore la rapidité.
  • Résumé de réservation toujours visible avant la confirmation pour réduire les erreurs.
  • Hiérarchie claire : titre, action principale, détails essentiels, puis confirmation.
  • Première page d’accès ajoutée pour simuler l’entrée dans le service sans imposer de vérification backend.
