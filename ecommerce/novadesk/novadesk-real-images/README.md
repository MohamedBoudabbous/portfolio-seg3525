# NovaDesk real HQ image downloader

Copy this folder content into `ecommerce/novadesk/`, then run:

```bash
chmod +x scripts/download-real-hq-images.sh
./scripts/download-real-hq-images.sh
```

The script downloads real Unsplash photos into `public/images/products/` and `src/data/products.js` already points to these local filenames.
